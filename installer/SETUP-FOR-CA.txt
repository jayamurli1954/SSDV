OfficeMitra — Setup guide for CA / Windows users
================================================
SanMitra Technologies
Website: https://www.sanmitratech.in
Support: contact@sanmitratech.in

You need TWO files from the package / Google Drive folder:
  1. OfficeMitra-Setup.exe   — install the app
  2. ssdv.sqlite             — demo company books (ABC Industrial)

You do NOT need to install Python.


------------------------------------------------
PART A — Download both files
------------------------------------------------
1. Open the Google Drive link you received.
2. Download OfficeMitra-Setup.exe (about 100 MB).
3. Download ssdv.sqlite (about 16 MB).
4. Save both to your Downloads folder or Desktop.

If Google Drive says "Can't preview" — that is normal.
Click Download (three-dot menu if needed).


------------------------------------------------
PART B — Install OfficeMitra
------------------------------------------------
1. Double-click OfficeMitra-Setup.exe.
2. If Windows shows "Windows protected your PC":
      More info  →  Run anyway
3. Click Next → Install → Finish.
4. Use the OfficeMitra icon on the Desktop (or Start menu).


------------------------------------------------
PART C — Put ssdv.sqlite in the data folder
------------------------------------------------
This file is NOT uploaded inside the app.
You COPY it into OfficeMitra's data folder.

1. Press Windows key + R.
2. Paste this and press Enter:

      %LOCALAPPDATA%\OfficeMitra\data

3. If the "data" folder does not exist:
      - Go up one level to the OfficeMitra folder
      - Right-click → New → Folder → name it: data
      - Open the data folder

4. Copy ssdv.sqlite from Downloads into this data folder.

5. You should now have a file like:
      C:\Users\<YourName>\AppData\Local\OfficeMitra\data\ssdv.sqlite

Tip: If AppData is hard to find, open File Explorer and paste
the same path (%LOCALAPPDATA%\OfficeMitra\data) in the address bar.


------------------------------------------------
PART D — Open OfficeMitra and load the demo books
------------------------------------------------
1. Double-click OfficeMitra on the Desktop.
2. Leave the small "OfficeMitra is running" window OPEN.
3. Your browser should open http://localhost:8501
   If not, open Chrome or Edge and go to that address.

4. In the LEFT SIDEBAR:
   - Vault  → choose  ssdv.sqlite
   - As of  → set  31 March 2026
     (or click "Use ABC year-end 31 Mar 2026" if shown)

5. Choose a pack:
   - CEO pack   — sales, margin, cash
   - CFO pack   — aging, cash forecast, vendors
   - Board pack — red flags + PDF download


------------------------------------------------
PART E — Daily use
------------------------------------------------
Open:   Desktop icon "OfficeMitra"
Close:  Close the browser tab, then close the OfficeMitra window

If sales look zero / wrong:
  - Vault must be ssdv.sqlite
  - As of must be 31 Mar 2026 for this demo


------------------------------------------------
PART F — Later: load a real client (CSV / Tally)
------------------------------------------------
1. Sidebar → Change data source (or Connect).
2. Choose source (Tally XML, CSV, etc.).
3. Upload the export (+ ledger map if asked).
4. After import, select vault: ssdv_connect.sqlite

Remember:
  ssdv.sqlite          = demo / training books
  ssdv_connect.sqlite  = your imported client books


------------------------------------------------
Troubleshooting
------------------------------------------------
SmartScreen blocks install
  → More info → Run anyway

Browser blank / cannot connect
  → Open http://localhost:8501
  → Check the OfficeMitra window is still open

ssdv.sqlite not in Vault list
  → Confirm file is in %LOCALAPPDATA%\OfficeMitra\data
  → Restart OfficeMitra

Google Drive "You need access"
  → Ask sender to set link to: Anyone with the link → Viewer
